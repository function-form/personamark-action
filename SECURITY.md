# Security

## Reporting a vulnerability

Please report security problems in this action privately, not in a public issue:

**[Report a vulnerability](https://github.com/function-form/personamark-action/security/advisories/new)**

You need a GitHub account to use the form. Only the maintainers can see what you send.

Please include the action version or commit, the workflow setup that triggers the problem, the steps to reproduce it, and what an attacker gains, such as access to the `PERSONAMARK_API_KEY` secret or a token with write access.

We'll reply within 3 working days, keep you updated while we fix it, and credit you in the release notes unless you'd rather we didn't.
